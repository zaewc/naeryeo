# 제품 구현 진행

2026-10-04 사용자 지시로 일반 사용자 Now Bar 표시 검증을 후속 제품 개발의 선행 조건에서 해제했다.
표시가 성공했다고 기록하는 것은 아니다. 기존 실기기 결과와 Samsung 문의는 그대로 유지한다.
우선 지원 지역은 광주 버스다. 공통 도메인 → 테스트 운행 → 공식 API → 백그라운드 추적 순으로 구현한다.

## 실제 데이터 연결

[광주버스정보 공식 API](https://www.data.go.kr/data/15157923/openapi.do)는 정류소, 노선,
노선별 경유 정류소, 도착정보, 버스위치를 제공한다. 인증키가 필요하며 개발 활용신청은 자동승인으로 안내된다.
확인한 페이지의 개발계정 신청 가능 트래픽은 100이므로 실시간 polling 정책은 실제 승인 한도 확인 후 설정해야 한다.
API 키를 앱 번들·EXPO_PUBLIC 변수·저장소에 넣지 않는다. 서버에서 보관하고 정규화된 데이터만 앱에 전달한다.
현재 인증키·실제 API 응답이 없어 실제 광주 차량 추적은 검증되지 않았다.

## 공통 진행 계산

정류장 ID와 노선 내 순번을 구분한다. 순환 노선에서 같은 정류장을 재방문할 수 있다.
남은 정거장은 순번 차이가 아닌 탑승 이후 목적지까지 실제 경유 정류장 개수로 계산한다.
차량 노선 불일치·존재하지 않는 순번·역방향 목적지·미래 관측을 거부한다.
오래된 차량 관측은 stale로 구분하고 ETA를 실시간 예측으로 노출하지 않는다.
